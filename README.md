# Folder Sync by Index

Утилита для копирования только новых и изменённых файлов по заранее подготовленному индексу.

## Что делает

- сканирует каталог и создаёт индекс файлов с хешами SHA-256;
- хранит пути относительно корня папки, а не по абсолютному адресу диска;
- сравнивает текущие файлы с индексом по относительному пути и содержимому;
- копирует только те файлы, которых нет в индексе или которые были изменены;
- работает даже если на двух компьютерах папки лежат в разных местах (`C:` / `E:` / `D:`);
- подходит для переноса на флешку, внешний диск или другой компьютер без сети.

## Почему это полезно

Когда папка очень большая, копировать её целиком на флешку или внешний диск неудобно или невозможно по объёму. С индексом можно:

- один раз сделать полный индекс;
- на другом компьютере копировать только актуальные файлы;
- повторно запускать утилиту и получать только новые/изменённые элементы;
- не трогать уже совпадающие файлы.

## Как использовать

### 1. Создать индекс

```bat
sync_new_files.exe scan "C:\files\sync_folder" --index "D:\index\sync_index.json"
```

Или через bat-скрипт:

```bat
run_scan.bat "C:\files\sync_folder" "D:\index\sync_index.json"
```

### 2. Копировать только новые и изменённые файлы

```bat
sync_new_files.exe copy "E:\kolo\fjfd\sync_folder" "F:\flash\copy_here" --index "D:\index\sync_index.json"
```

Или:

```bat
run_sync.bat "C:\files\sync_folder" "D:\index\sync_index.json" "E:\kolo\fjfd\sync_folder" "F:\flash\copy_here"
```

### 3. Проверить без копирования

```bat
sync_new_files.exe copy "E:\kolo\fjfd\sync_folder" "F:\flash\copy_here" --index "D:\index\sync_index.json" --dry-run
```

Или:

```bat
run_dry_run.bat "E:\kolo\fjfd\sync_folder" "D:\index\sync_index.json" "F:\flash\copy_here"
```

## Принцип работы

Индекс хранит данные по файлам в виде:

- относительный путь внутри корневой папки;
- хеш SHA-256;
- размер файла;
- время изменения.

При каждом запуске утилита сравнивает текущий файл с данными из индекса:

- если файла нет — копирует;
- если хеш отличается — копирует;
- если всё совпадает — пропускает.

Важно: в индексе нет абсолютного пути к папке, поэтому один и тот же JSON подходит и для `C:\...`, и для `E:\...`, если содержимое одно и то же.

## Требования

- Windows
- исполняемый файл `.exe` или Python 3.11+

## Файлы проекта

- `sync_new_files.py` — основной Python-скрипт;
- `dist/sync_new_files.exe` — собранная Windows-утилита;
- `run_sync.bat` — быстрый запуск копирования;
- `run_scan.bat` — создание индекса;
- `run_dry_run.bat` — предварительная проверка;
- `tests/test_sync_new_files.py` — проверка логики.

## Примечание

Индекс — это не резервная копия, а справочник по содержимому файлов. Он нужен для выбора только актуальных элементов при копировании.
